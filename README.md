# claude_monitor

Мониторинг лимитов Claude: виджет в строке меню и строка статуса внутри Claude Code.

## Запуск

```bash
git clone https://github.com/ivan-moskvin/claude_monitor.git
cd claude_monitor
./run.sh          # Windows: .\run.ps1
```

Скрипт соберёт всё из исходников и запустит виджет. Приложение живёт прямо в клоне
репозитория — в систему ничего не ставится, подписывать и разрешать нечего.
Нужны `go`, `node` и `rust`; чего не хватает — скрипт назовёт и подскажет команду.

Дальше всё из попапа: автозапуск и установка строки статуса.

```bash
git pull && ./run.sh      # обновить: пересоберёт и перезапустит
pkill -x claude-usage-bar # остановить
```

Автозапуск и строка статуса ссылаются на бинарь в клоне, поэтому репозиторий
лучше не переносить — после переезда достаточно снова запустить `./run.sh`.

## Откуда берутся данные

Claude Code получает от API служебные заголовки `anthropic-ratelimit-unified-*` и по ним считает
расход 5-часового и недельного окон. Эти цифры он передаёт statusline-команде на stdin
в поле `rate_limits`.

Команда печатает строку статуса и попутно сохраняет лимиты в `~/.claude/usage-snapshot.json`.
Виджет читает этот файл — никаких сетевых запросов, токенов и обращений к Keychain.
Формат файла описан в [docs/PROTOCOL.md](docs/PROTOCOL.md).

Данные обновляются только пока запущена сессия Claude Code. Когда сессий нет, расход не растёт,
поэтому виджет показывает последнее известное значение с пометкой о его возрасте, а
сброшенное окно гасит — старые проценты больше не описывают текущий расход.

## Строка статуса

```
Opus 5 · 5h ▕   24%    ▏ · сброс ▕  2ч 45м  ▏
```

Заполненная часть полосы выводится инверсией, поэтому проценты и обратный отсчёт
читаются прямо внутри шкалы.

## Виджет

Кольцо в строке меню показывает 5-часовое окно: зелёное до 60%, оранжевое до 85%, дальше красное.
В попапе — два кольца (внешнее 5 часов, внутреннее неделя), часы с временем до сброса, легенда
с процентами и настройки.

## Устройство репозитория

```
statusline/        writer на Go — общий для всех платформ
app/               виджет на Tauri: src/ (интерфейс), src-tauri/ (Rust)
tools/icon/        генератор исходника иконки
docs/PROTOCOL.md   контракт usage-snapshot.json
```

Windows-версия переиспользует `statusline/` и `app/` как есть — платформенным остаётся
только скрипт запуска.

## Разработка

Нужны Go, Rust и Node:

```bash
brew install go rustup node
rustup default stable
```

`./run.sh` пересобирает и перезапускает виджет. Интерфейс с перезагрузкой:

```bash
cd app && npm install && npm run dev
```
