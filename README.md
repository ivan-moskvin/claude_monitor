# claude_monitor

Лимиты Claude в строке статуса Claude Code — видно во время работы, без `/usage`.

## Установка

```bash
git clone https://github.com/ivan-moskvin/claude_monitor.git
cd claude_monitor
./run.sh
```

Windows — `.\run.ps1`.

Нужен `go` — если его нет, скрипт доустановит сам (`brew`, в Windows `winget`),
спросив разрешение. Без вопросов — с ключом `--yes`.

Скрипт соберёт бинарь в `bin/` и пропишет его в `~/.claude/settings.json`.
Прежние настройки сохраняются рядом, в `settings.json.bak`. Строка появится
в следующей сессии Claude Code.

Обновиться — `git pull` и снова запустить скрипт. Настройки ссылаются на бинарь
в клоне, поэтому репозиторий лучше не переносить: после переезда достаточно
запустить скрипт заново.

## Строка статуса

Модель, текущий уровень `/effort`, пятичасовое окно, время до его сброса и недельное
окно. Круг рядом с моделью заполняется от `low` (`○`) до `max` (`●`). Цвет полос —
по расходу: зелёный до 60%, оранжевый до 85%, дальше красный.

![Состояния строки статуса](docs/statusline-demo.png)

## Как это работает

Лимиты приходят от самого Claude Code: он подаёт statusline-команде JSON сессии
на stdin, а `rate_limits` оттуда и печатаются. Никаких сетевых запросов, токенов
и обращений к Keychain — исходники открыты, чтобы это можно было проверить.

Цифры обновляются только пока идёт сессия: строку статуса рисует сам Claude Code.
