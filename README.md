# claude_monitor

Мониторинг лимитов Claude: строка статуса внутри Claude Code и виджет в menu bar macOS.

## Откуда берутся данные

Claude Code получает от API служебные заголовки `anthropic-ratelimit-unified-*` и по ним считает расход
5-часового и недельного окон. Эти цифры он передаёт statusline-скрипту на stdin в поле `rate_limits`:

```json
{
  "rate_limits": {
    "five_hour": { "used_percentage": 12, "resets_at": 1785324000 },
    "seven_day": { "used_percentage": 7, "resets_at": 1785636000 }
  }
}
```

`used_percentage` — число 0–100, `resets_at` — Unix timestamp в секундах.

Скрипт печатает строку статуса и попутно сохраняет лимиты в `~/.claude/usage-snapshot.json`.
Виджет читает этот файл — никаких сетевых запросов, токенов и обращений к Keychain.

Данные обновляются только пока запущена сессия Claude Code. Когда сессий нет, расход не растёт,
поэтому виджет показывает последнее известное значение с пометкой о его возрасте.

## Строка статуса

```
5h █░░░░░░░░░ 12% (2ч 46м) · 7d █░░░░░░░░░ 7% · Opus 5
```

Установка на любой машине — один самодостаточный скрипт:

```bash
./install-statusline.sh
```

Он пишет `~/.claude/statusline.py`, прописывает `statusLine` в `~/.claude/settings.json`
(остальные настройки не трогает, делает `.bak`) и предупреждает, если `statusLine` уже занят.
Дальше нужна новая сессия `claude`.

Требуется `python3` — на macOS приходит с Command Line Tools.

## Виджет в menu bar

Кольцо в строке меню показывает 5-часовое окно; зелёное до 60%, оранжевое до 85%, дальше красное.
В попапе — два кольца (внешнее 5 часов, внутреннее неделя), часы с временем до сброса и легенда с процентами.

```bash
./build.sh
open build/ClaudeUsageBar.app
```

Собирается SwiftPM без Xcode-проекта; `build.sh` упаковывает бинарь в `.app` с `LSUIElement`
и подписывает ad-hoc. Требуется macOS 14+.

Подпись ad-hoc меняется при каждой сборке — для постоянной установки лучше подписать
собственным сертификатом (`CODESIGN_IDENTITY=... ./build.sh`).
