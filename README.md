# claude_monitor

Лимиты Claude в строке статуса Claude Code — видно во время работы, без `/usage`.

## Установка

```bash
git clone https://github.com/ivan-moskvin/claude_monitor.git
cd claude_monitor
./run.sh
```

Windows — `.\run.ps1`.

Нужен `go` — если его нет, скрипт доустановит сам (`brew`, в Windows `winget`),
спросив разрешение. Без вопросов — с ключом `--yes`.

Скрипт соберёт бинарь в `bin/`, пропишет его в `~/.claude/settings.json` и положит
ссылку `claudestatus` в `~/.local/bin` (Windows — добавит `bin\` в PATH). Прежние
настройки сохраняются рядом, в `settings.json.bak`. Строка появится в следующей
сессии Claude Code.

## Обновление

```bash
claudestatus update
```

Утилита сама сходит за тегами в origin, переключит клон на последний, пересоберёт
бинарь и перепропишет строку статуса. Раз в сутки клон проверяется на новый тег
в фоне — если он вышел, в строке статуса загорается `↑ v1.2.3`. Отключить проверку:
`CLAUDESTATUS_NO_AUTO_UPDATE=1`.

Бинарь живёт в клоне, настройки ссылаются прямо на него — репозиторий лучше
не переносить: после переезда достаточно запустить `./run.sh` заново.

## Команды

```
claudestatus            строка статуса: JSON сессии на stdin, строка на stdout
claudestatus install    прописать себя в ~/.claude/settings.json
claudestatus check      проверить, вышел ли новый тег
claudestatus update     обновиться до последнего тега и пересобраться
claudestatus version    показать версию
```

## Строка статуса

Модель, текущий уровень `/effort`, пятичасовое окно, время до его сброса и недельное
окно. Круг рядом с моделью заполняется от `low` (`○`) до `max` (`●`). Цвет полос —
по расходу: зелёный до 60%, оранжевый до 85%, дальше красный.

## Как это работает

Лимиты приходят от самого Claude Code: он подаёт statusline-команде JSON сессии
на stdin, а `rate_limits` оттуда и печатаются. Никаких запросов к API Anthropic,
токенов и обращений к Keychain — исходники открыты, чтобы это можно было проверить.
В сеть утилита ходит только за обновлениями и только в git: `git fetch --tags`
у своего же origin.

Цифры обновляются только пока идёт сессия: строку статуса рисует сам Claude Code.
