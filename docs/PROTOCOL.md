# Контракт `usage-snapshot.json`

Единственная связь между writer'ом и виджетом. Всё остальное — детали реализации
конкретной платформы, и меняться они могут независимо.

## Расположение

| Платформа | Путь |
|---|---|
| macOS, Linux | `~/.claude/usage-snapshot.json` |
| Windows | `%USERPROFILE%\.claude\usage-snapshot.json` |

Каталог тот же, где Claude Code держит `settings.json`.

## Формат

```json
{
  "rate_limits": {
    "five_hour": { "used_percentage": 24, "resets_at": 1785324000 },
    "seven_day": { "used_percentage": 8, "resets_at": 1785636000 }
  },
  "updated_at": "2026-07-29T08:57:51.585680+00:00"
}
```

`rate_limits` — блок, который Claude Code передаёт statusline-скрипту на stdin, скопированный
без изменений: writer не выбирает поля, поэтому новые окна появятся в файле сами собой.

| Поле | Тип | Смысл |
|---|---|---|
| `used_percentage` | число 0–100 | Израсходовано в окне |
| `resets_at` | Unix-время | Момент сброса окна: секунды или миллисекунды |
| `updated_at` | ISO8601 | Когда writer записал файл |

Читатель различает секунды и миллисекунды по величине: значение больше `1e12` считается
миллисекундами. Обе стороны нормализуют одинаково.

## Гарантии записи

Writer пишет во временный файл рядом (`usage-snapshot.tmp`) и переименовывает его поверх
снапшота. Читатель никогда не видит половину записи и может читать без блокировок.

Файл переписывается только когда Claude Code вызвал statusline с непустым `rate_limits`.

## Три состояния читателя

Снапшот обновляется исключительно во время активной сессии Claude Code. Без сессий цифры
замирают, поэтому виджет обязан различать:

| Состояние | Условие | Как показывать |
|---|---|---|
| Свежие данные | возраст < 90 с | Обычный вид |
| Устаревшие | возраст ≥ 90 с | Подпись с относительным возрастом |
| Окно сброшено | `resets_at <= now` | Проценты описывают прошлое: гасить цвет, убирать обратный отсчёт |

Третье состояние — не то же самое, что второе: окно могло сброситься при свежем снапшоте.
Показывать в этот момент старый процент как текущий расход нельзя.

## Пороги цвета

До 60% — базовый цвет окна, до 85% — оранжевый, дальше красный. Сброшенное окно — серый.
Базовый цвет различается по окнам (зелёный у 5-часового, голубой у недельного), поэтому
порог и базовый цвет разделены.
